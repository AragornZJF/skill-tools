# 账单解析指南

> 各来源账单截图的字段识别规则。AI 读取图片后按此指南提取 5 个字段。

## 通用字段说明

| 字段 | 说明 | 格式要求 |
|---|---|---|
| 金额 | 交易金额，支出为负数，收入为正数 | 数字，保留两位小数，如 -128.50 |
| 收款方备注 | 收款方名称 + 转账备注（如有） | 文本，收款方和备注用空格连接 |
| 支付方式 | 交易渠道 | 微信 / 支付宝 / 银行卡 / 现金 等 |
| 转账时间 | 交易发生时间 | YYYY-MM-DD HH:MM |
| 转账单号 | 交易唯一标识 | 数字串，尽量完整提取 |

## 微信账单截图

### 识别要点

微信转账/账单截图通常包含以下信息区域：

1. **金额**：通常在截图上部居中位置，大号字体显示。前面可能有"-"表示支出。
   - 格式示例："-128.50" 或 "￥128.50"
   - 注意区分支出和收入：转出（支出）为负，转入（收入）为正

2. **收款方**：在金额下方，标注"收款方"或"转账给"
   - 如果有备注，通常在"转账说明"或"备注"字段中

3. **转账时间**：在交易详情中，标注"转账时间"或"当前状态"旁的时间
   - 格式通常为"2026年08月15日 14:30:05"

4. **转账单号**：在详情页底部，标注"转账单号"或"交易单号"
   - 通常为 28 位数字串，如"1000050001202608151430056789"

5. **支付方式**：微信截图默认支付方式为"微信"
   - 如果显示"零钱"、"银行卡"等，记录为"微信(零钱)"、"微信(银行卡)"

## 支付宝账单截图

### 识别要点

1. **金额**：截图上部居中，大号字体
   - 支付宝通常用红色表示支出，蓝色表示收入
   - 格式示例："-128.50" 或 "128.50元"

2. **收款方/付款方**：标注"对方账户"或"收款方"
   - 可能有商户名称、备注信息

3. **转账时间**：标注"创建时间"或"付款时间"
   - 格式通常为"2026-08-15 14:30:05"

4. **转账单号**：标注"交易号"或"订单号"
   - 通常为 28-32 位数字串

5. **支付方式**：标注"付款方式"
   - 可能是"余额"、"花呗"、"银行卡"等
   - 统一记录为"支付宝(余额)"、"支付宝(花呗)"、"支付宝(银行卡)"等

## 银行转账截图

### 识别要点

1. **金额**：转账金额，通常带"元"或货币符号
   - 转出为负数，转入为正数

2. **收款方**：标注"收款人"或"对方账户"
   - 可能有附言/备注

3. **转账时间**：标注"交易时间"或"转账时间"
   - 格式通常为"2026/08/15 14:30:05"或"2026-08-15 14:30"

4. **转账单号**：标注"流水号"或"交易流水号"或"电子回单单号"
   - 不同银行格式不同，通常为数字+字母混合

5. **支付方式**：记录银行名称 + 卡类型
   - 如"工商银行(借记卡)"、"建设银行(信用卡)"

## 金额正负规则

| 交易方向 | 金额符号 | 说明 |
|---|---|---|
| 转出/支出 | 负数（-） | 钱从公司账户出去 |
| 转入/收入 | 正数（+） | 钱进入公司账户 |
| 不明确 | 按上下文判断 | 如截图显示"已收款"则为收入 |

## 解析失败处理

1. **图片模糊**：无法辨认某字段时，向用户确认该字段值
2. **字段缺失**：截图中没有某字段时，用"-"占位，向用户说明
3. **多笔交易**：一张截图中含多笔交易时，分别提取每笔记录
4. **非账单图片**：图片不包含账单信息时，告知用户无法识别

## 单号提取注意

- 转账单号可能跨行显示，需拼接完整
- 不同平台单号长度不同，不要截断
- 单号是去重唯一标识，必须尽可能完整提取
- 如果无法提取到单号，使用"时间+金额+收款方"组合作为临时标识，并提醒用户
