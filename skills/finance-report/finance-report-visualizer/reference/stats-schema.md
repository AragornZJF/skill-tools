# 数据格式规范（YYYY-MM-stats.md）

本技能读取一个目录下的所有 `YYYY-MM-stats.md` 文件（每月一份），解析其中的财务报表数据。

## 文件命名
- 必须严格匹配：`YYYY-MM-stats.md`，例如 `2026-08-stats.md`、`2025-12-stats.md`。
- 文件名中的 `YYYY-MM` 用于补齐表格里缺失的年月。

## 表格结构
文件内只需包含一张 Markdown 表格，表头使用下列字段（顺序不限）：

| 字段 | 含义 | 是否必填 | 别名（识别时兼容） |
|------|------|----------|--------------------|
| 日期 | 当月日或完整日期 | 必填 | 日期 / date / 时间 |
| 收入 | 当期收入 | 必填 | 收入 / 营收 / revenue |
| 支出 | 当期支出 | 必填 | 支出 / 成本 / 费用 / expense |
| 经营现金流 | 经营活动现金流量 | 可选 | 经营现金流 / 经营活动现金流 |
| 投资现金流 | 投资活动现金流量 | 可选 | 投资现金流 / 投资活动现金流 |
| 筹资现金流 | 筹资活动现金流量 | 可选 | 筹资现金流 / 筹资活动现金流 |
| 净利润 | 净利润（缺省则 = 收入 − 支出） | 可选 | 净利润 / 利润 |

> 净利润若在表中给出则优先使用表值；若缺失，解析器自动按 `收入 − 支出` 派生。
> 三类现金流任一缺失，按 0 处理。

## 日期单元格写法（任选其一）
- 当月日：`01` ~ `31`（按文件名年月补齐）
- 月内区间：`1/15`、`01/31`
- 完整日期：`2026-08-15`、`2026/08/15`

## 金额单元格写法
- 普通数字：`12000`、`8,000`（逗号自动忽略）
- 负数：`-2000` 或括号 `(2000)`
- 空 / 占位：`-`、`—`、`无`、`N/A` 均按 0 处理
- 可带货币符号：`¥12000`、`12000元`（自动剥离）

## 完整示例
```markdown
# 2026-08 财务统计

| 日期 | 收入 | 支出 | 经营现金流 | 投资现金流 | 筹资现金流 |
|------|------|------|-----------|-----------|-----------|
| 01   | 12000 | 8000 | 4000  | -2000 | 0     |
| 02   | 15000 | 9000 | 6000  | 0     | -1000 |
| 03   | 13500 | 8200 | 5300  | -500  | 200   |
| ...  | ...   | ...  | ...   | ...   | ...   |
```

## 最小可用示例（缺现金流列）
```markdown
# 2026-08 财务统计

| 日期 | 收入 | 支出 |
|------|------|------|
| 01   | 12000 | 8000 |
| 02   | 15000 | 9000 |
```
此时净利润自动派生，现金流图将全为 0。
