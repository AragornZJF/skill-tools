测试与优化
跨浏览器兼容与交互流畅性。最后一步强制四项自检（缺一不可）：
强制自检 · 硬性约束
a
样式检查
选择器与属性拼写（类名缺 . 前缀致整条失效）；后代选择器特异性——.parent img 误匹配嵌套头像，改 .parent > img；z-index 层级：模态框盖 Tab、FAB 不被遮挡。
零样式错乱、零遮挡
b
布局展示
内容溢出/横向滚动条——.page-body 禁止写死 375px（撑出 iframe 视口），用 width:100%; max-width:375px；变形压缩——object-fit / aspect-ratio 冲突撑图。
自适应容器、无溢出
c
图片可达性
每个 <img> 真实可访问（HTTP 200 逐一 curl 验证），任一 404/400 立即换图重验，交付时零失败。
100% 可达、零占位符
d
作者署名
grep openQrcodeModal 在 login.html 与 profile.html 各命中一次；署名 帮助？@Auth 江枫 点击弹二维码。
双页命中、弹窗可用
